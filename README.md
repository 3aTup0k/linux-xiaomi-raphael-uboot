# Проект сборки образов Linux для устройства Xiaomi Raphael

Этот проект предоставляет скрипты сборки образов Debian/Ubuntu Linux и автоматизированные рабочие процессы для устройства Xiaomi Raphael (Redmi K20 Pro) с поддержкой графических окружений и серверной версии.

## 📋 Обзор проекта

Проект содержит полную цепочку инструментов сборки, позволяющую создавать образы Linux-систем для устройства Xiaomi Raphael, включая:

- **Рабочий процесс компиляции ядра** — автоматизированная сборка кастомного ядра Linux
- **Debian GNOME** — система Debian с графической средой GNOME
- **Debian Phosh** — система Debian с графической средой Phosh
- **Debian Server** — серверная система Debian без графического интерфейса
- **Ubuntu GNOME** — система Ubuntu с графической средой GNOME
- **Ubuntu Phosh** — система Ubuntu с графической средой Phosh
- **Ubuntu Server** — серверная система Ubuntu без графического интерфейса

## 🚀 Быстрый старт

### Автоматическая сборка с помощью GitHub Actions

1. **Сделайте форк репозитория** к себе в аккаунт GitHub

2. **Сборка ядра**:
   - Откройте вкладку Actions в вашем репозитории
   - Выберите рабочий процесс "Компиляция ядра" (内核编译)
   - Нажмите "Run workflow"
   - Введите версию ядра (например, `6.18`)
   - Дождитесь завершения сборки; артефакты будут автоматически опубликованы в Releases

3. **Сборка системного образа**:
   - Выберите рабочий процесс "Сборка системного образа" (构建系统镜像)
   - Нажмите "Run workflow"
   - Выберите тип системы:
       - `debian-gnome` — Debian с GNOME
       - `debian-phosh` — Debian с Phosh
       - `debian-server` — серверный Debian
       - `ubuntu-gnome` — Ubuntu с GNOME
       - `ubuntu-phosh` — Ubuntu с Phosh
       - `ubuntu-server` — серверный Ubuntu
   - Версия ядра:
       - `версия ядра, собранная на предыдущем шаге`
   - Выберите вариант графической среды (только для версий Phosh; для GNOME и серверных версий не выбирается):
       - `phosh-core` — базовая среда Phosh
       - `phosh-full` — полная среда Phosh
       - `phosh-phone` — Phosh, оптимизированная для телефона
   - Дождитесь завершения сборки; образ будет автоматически опубликован в Releases

## 🔧 Установка на устройство

### Подготовка
1. **Разблокируйте загрузчик**: Убедитесь, что загрузчик устройства разблокирован
2. **Установите инструменты**: Установите `fastboot` и `adb`

### Шаги по прошивке

```bash
# 1. Перезагрузитесь в режим Fastboot
adb reboot bootloader

# 2. Очистите разделы
fastboot erase dtbo
fastboot erase boot
fastboot erase cache
fastboot erase userdata

# 3. Прошейте загрузочные образы
fastboot flash cache xiaomi-k20pro-boot.img
fastboot flash boot u-boot.img

# 4. Прошейте образ системы (предварительно распакуйте rootfs.7z)
fastboot flash userdata rootfs.img

# 5. Перезагрузите устройство
fastboot reboot
```

## ❓ Часто задаваемые вопросы (FAQ)

- [Решение проблемы с драйвером CDC NCM в Windows](https://www.bilibili.com/video/BV1tW4y1A79V/)

- Как подключиться к сети в серверной версии???
	- 1. Подключите Ethernet-кабель через OTG — система определит его автоматически
	- 2. Подключите клавиатуру через OTG и выполните `nmtui` для подключения к Wi-Fi
	- 3. Подключите устройство к компьютеру по USB, установите драйвер NCM и выполните `nmtui` для подключения к Wi-Fi
